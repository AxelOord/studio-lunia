# Reusable page blocks — provisional content review

Spec: [003-reusable-page-blocks](../specs/003-reusable-page-blocks/requirements.md).
In Pages → Layout, use Add Layout, select a block, then Insert. Blocks can be reordered
with the standard Payload controls. Save Draft preserves unpublished work; use Preview
while signed in. Existing hero/text/gallery content remains supported.

| Block          | Editor controls                                      | Rendering                                               |
| -------------- | ---------------------------------------------------- | ------------------------------------------------------- |
| Hero           | Eyebrow, heading, body, optional image               | Existing opening image/copy layout                      |
| Text           | Heading and body                                     | Centered readable text                                  |
| Gallery        | Heading and up to 12 images                          | Two visible images form a pair; otherwise three columns |
| Image and text | Heading, body, image, image side                     | Left/right split; copy then image on mobile             |
| Service cards  | Heading, optional introduction, 1–6 title/body items | Simple editable information cards                       |
| Call to action | Heading, optional body, label, page path             | Keyboard-accessible internal link                       |

CTA paths support `/` or a single lowercase page slug, such as `/sessions`. The editor
must choose an existing page; validation checks path syntax, not destination existence.
No external URL, tracking query or booking action is introduced. Text is plain and escaped.
A private image is visible only in authenticated draft preview; publishing its page does
not publish the image. Missing/restricted image/text media displays a neutral placeholder.

Styling uses existing warm paper/ink tokens and system serif headings. The reference
Library item `image(6).png` was resolved, but its download failed twice in this executor;
no readable image bytes were available. Library's extracted description supported only
the broad editorial direction. No pixel-level comparison or final styling approval is claimed.
Real logos, fonts, photographs and copy remain pending. Testimonials are intentionally
absent until authentic, approved quotes exist; tests use labelled synthetic colour studies.
